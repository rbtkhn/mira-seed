# Essays

Empty by design.

This shelf holds developed standalone prose authored in this repository under the
vendored `mira-essays` contract — writing meant to stand for a reader who was not
present for the work behind it.

Nothing is inherited into it. The `essay this` publication shorthand present
upstream is deliberately absent, as the
[vendored contract](../../docs/skill-drafts/mira-essays/SKILL.md) records.
Presence in this repository is not publication, and it never authorizes public
representation.

An essay written here will be the first thing this repository says in its own
voice rather than a borrowed one. That is worth waiting for rather than filling.
