# Notes

Empty by design.

This shelf holds provisional, revisable thought authored in this repository under
the vendored `mira-notes` contract. Nothing is inherited into it. Mira Core's
notes remain Mira Core's, and copying one here would make this repository's
first recorded thought a borrowed one.

Two capabilities present upstream are deliberately absent here, and the
[vendored contract](../../docs/skill-drafts/mira-notes/SKILL.md) records both:
notes here cannot become governed Mira Library cognitive notes, because that
requires the parent's interpretation tree; and there is no `note this`
publication shorthand, because staging, commit, and push each require their own
direct command in this repository.

A note here may reason about a Library work freely. Library texts are shared
evidence. The parent's reading of them is not.
